# 第六轮RBF迭代结果与使用说明

日期：2026-10-15。当前结果来自已有60工况数据；没有新增Maxwell仿真输出。

本轮完成420组逐点RBF参数对照、4次真实高斯RBF神经网络梯度训练，以及3个区域的51工况RBF分支重拟合。RBF增强版平均预测误差进一步下降；转子、定子仍未低于1%。气隙平均误差下降，但最大单点误差上升。

## 用了什么RBF方法

1. 逐测点、完整60位置的RBF回归：利用训练数据估计每个点对两维电流坐标的主要响应方向，沿该方向设置不同长度尺度。对高斯、逆多二次、多二次、Matérn 5/2四类径向核，各比较长度尺度、正则强度、各向异性与饱和坐标。每条路线84组，转子Br/Bt和磁密大小两条、定子两条、气隙Br一条，共420组。

每点的核参数按训练工况的条件留一误差选择。响应方向与归一化仍在该训练集上计算，所以这不是完整嵌套交叉验证，留一误差仅用于选择参数，不能作为独立预测精度。所有空间点都保留。最终RBF比例及共享/逐点路线按完整原9验证工况的磁密大小或Br RMSE选定。

最终转子：50%旧混合模型磁密大小+50%新RBF磁密大小；新RBF在求磁密大小前，将共享核和逐点核的Br/Bt结果各占50%组合。最终定子同样组合，但旧基线占75%、RBF占25%。最终气隙：原基线Br与新共享RBF Br各占50%。

2. 真实RBF神经网络：在冻结的V5转子神经网络上增加高斯RBF残差分支，每个点8或16个高斯单元，中心、两个方向的宽度、输出权重、线性支路均由PyTorch/Adam学习。预测Br/Bt的平均值修正，冻结原位置变化分支。损失是原始T单位磁密大小MSE，加0.02或0.2倍平均Br/Bt分量约束。每次1200步，共4次。

4次训练的最佳验证检查点均在第50步，较长训练出现过拟合；最佳相对L2为2.496579%，没有胜过所选解析RBF混合方案的2.328794%。因此本轮发布的提升不能说成纯神经网络提升。RBF核回归也不能冒称端到端训练的RBF神经网络。

RBF形状参数、平滑参数及其病态风险参考SciPy官方说明：https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.RBFInterpolator.html 。

## 拟合误差与适用范围

V3/V5全60工况训练内拟合模型保持不变，误差接近浮点数值精度。该结果只表示已知60工况的标签重现，不能代表新工况预测或Maxwell物理误差。V6训练没有使用这些全60拟合模型的标签。

转子和定子输出为二维磁密大小sqrt(Br²+Bt²)，不是单独Br；气隙输出为保留正负号的Br。电流使用原生RMS值，电流角沿用原生Thet，不擅自等同dq角；磁密T、坐标mm。每个工况仅支持已提供的60个转子位置，不把选帧称为任意新转角预测。空间为原测量扇区；3D图的高度表示磁密值，不是电机三维体积。等测点权重，不是有限元面积加权。

最大误差仍明显，转子同一测点ID3551附近的响应仍需要真实补充工况和测点审计。尚无证据可将它归因于噪声或材料界面问题；未删除、平滑或隐藏难点。气隙V6平均误差较小但峰值变大，保留V5以供峰值优先的比较。

## 文件与复现

完整V6包继承整个V5完整交付并增加new60_opt_v6，原始数据、旧神经网络、核模型及全60拟合权重都保留。先阅读根目录V6先读说明。环境沿用V5，推理需要NumPy与threadpoolctl，RBF神经网络训练另需PyTorch。

从解压根目录运行（python可换成自己的Python可执行文件）：

python new60_opt_v6/inference_v6.py --region rotor --current 360 --angle 54.4 --scope final51 --frame 0 --output rotor_prediction.npz

区域可选rotor/stator/airgap；scope可选original42/final51；frame为0至59，省略时输出60帧。输出npz包含prediction、单位及工况输入。

重新训练单条RBF路线示例：python new60_opt_v6/rbf_pointwise.py --region rotor --route signed。训练脚本防止覆盖已存在实验目录；完整从头复现应在副本中移开同名结果目录，保留冻结原始交付。评估脚本同样禁止覆盖已有评估目录。

主要文件：rbf_choices_pretest.json为测试前配方；iteration_frozen.json为正式评估前模型/源码SHA；evaluation/final_results.json为全部原精度结果；rbf_neural/为4次实际梯度训练；final51/为新增重拟合；figures/为全部图和CSV。

图文件：figures/01_average_and_peak_error.png、figures/rotor_2d_worst_frame.png、figures/rotor_3d_worst_frame.png，定子与气隙同名替换区域；figures/08_RBF_neural_learning_curves.png显示过拟合过程。
