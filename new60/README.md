# 新60工况 · 20261014实验

[可视化网站](https://xin02350-eng.github.io/maxwell-rotor-field-viewer/new60/) · [方法与测试结果](guide.html) · [原精度汇总](results.json)

60工况×60帧，定子1800点Br/Bt、转子1800点Br/Bt、气隙900点Br，5500rpm。默认case02为本轮9个留出测试工况之一。网页覆盖全部60工况的冻结预测，并明确train/validation/test；control和POD仅提供9个test。RMS电流与原生Thet角不改定义。

`research/`是新实验训练、验证冻结、测试和NumPy推理源码；完整研究目录、缓存、权重、训练日志、交接卡、高精度数据与图件在独立交付包中。仅克隆网页数据不能当作原精度训练集。训练所需原始合并文件为`flux60_s60_merged.npz`；不要用q16网页数据替代原始数组。

52次正式NN训练＋3次小样本诊断；四架构及损失/热点/困难帧/残差/LR对照共用固定预算。最终测试只在全部验证选择冻结后计算。模型并非全部优于纯RBF：定子和转子的纯RBF测试RMSE稍低，气隙混合模型更好。

本地运行：`python -m http.server 8782 --bind 127.0.0.1`，打开`http://127.0.0.1:8782/`。浏览器按需加载234个gzip载荷（单文件<0.88MB），q16单值量化误差<0.000046T，科学指标用未量化值。

只显示实际45°扇区测点。3D是磁密高度图；POD真值投影是重构诊断。时间与空间点固定，初始单电周期没有稳态认证。本轮新划分与原Round4不是同一可核对实验，不能替代旧PPT分数。
